An original flight game in plain browser JavaScript, no libraries: a voxel-rendered island chain,
a light monoplane with a chase camera and a lit cockpit, three missions (Ring Run, Ferry Flight,
Lighthouse Patrol), fuel, damage, glide-slope guidance, landings and crashes.

Controls: W/S pitch, A/D bank, Q/E rudder, Shift/Ctrl throttle, B brakes, C cockpit view, P pause;
click the screen to fly with the mouse.

## Run it

```sh
python -m http.server 8080 --directory game   # then open http://localhost:8080
```
